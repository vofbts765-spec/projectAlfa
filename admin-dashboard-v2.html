How publishing works

Save Draft stores your changes privately in Firestore. Preview sends the current draft to a preview copy of your website. Publish updates the public content document that the website reads. A version snapshot is saved when publishing.

Media is currently managed through image/video URLs. Direct file uploads are not enabled in this first build because Firebase Storage and its billing/usage settings have not been verified.

Original source protection

This build adds new CMS files and one additional runtime script reference. It does not remove your existing HTML, CSS, JavaScript, sections, animations, or website features.
